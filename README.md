# 🚢 Titanic Survival Prediction

A machine learning project that predicts whether a passenger would survive the Titanic disaster based on passenger information. The model is trained using the famous Kaggle Titanic dataset and is deployed through a simple Streamlit web application.

## 📌 Project Overview

The objective of this project is to build a classification model that predicts passenger survival using features such as age, gender, passenger class, fare, family size, and embarkation port.

## ✨ Features

* Data preprocessing and feature engineering
* Exploratory Data Analysis (EDA)
* Machine Learning model training
* Model evaluation and prediction
* Streamlit web application for real-time predictions
* Kaggle competition submission support

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/Anisa960/Titanic-Survival-Prediction.git
```

Move into the project directory:

```bash
cd Titanic-Survival-Prediction
```

Install the required packages:

```bash
pip install -r requirements.txt
```

Run the Streamlit application:

```bash
streamlit run app.py
```
